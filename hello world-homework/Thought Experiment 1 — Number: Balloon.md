Thought Experiment 1 — Number: Balloon
Data Type: Number
Dynamic Medium: Balloon
A balloon can represent a number. As the number increases, more air is added to the balloon and it gets bigger. As the number decreases, air is released and the balloon gets smaller.
For example, the balloon could represent stress. The more stressed someone feels, the bigger the balloon becomes. When the stress level gets very high, the balloon looks like it might burst.
Thought Experiment 2 — Array: People in Line
Data Type: Array
Dynamic Medium: People Waiting in Line
A line of people can represent an array. Each person represents one element in the array, and their position in the line represents their order.
When a new person joins the line, a new element is added. When someone leaves, an element is removed. If two people switch positions, the order of the array changes.
